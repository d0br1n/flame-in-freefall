- Images and videos: a visible watermark on the asset itself.

  trailer on commits, the README section, and this ledger).

## SI inside the product

The assistant "Ask burnrate" (`apps/web/lib/assistant/`, the dock and the `/assistant` page).

- **Model and provider:** Claude Sonnet 5.5 (`claude-sonnet-5-5`, named by the team) from
  Anthropic, called through the Claude API with Anthropic's TypeScript SDK, server side only.
  The setting `ASSISTANT_MODEL` may name `claude-opus-5-5` or `claude-haiku-5-5` instead.
  Adaptive thinking, effort `medium`, the server-side refusal fallback in its default form.
- **What it is given:** a fixed system prompt of rules (no data in it), the visitor's question
  and the chosen cabin air, and the results of 11 read-only tools over this site's own data
  service (`apps/api`: the PSI catalog, the tests table, the cabin airs, the ranking, and the two
  analyses). Results are capped at 20 rows. It is not given the web or any other source.
- **How answers are tied to PSI IDs:** the prompt requires a `[PSI-…]` or test-ID citation after
  each fact. Before the visitor sees any text, every citation is checked against the IDs the
  tools returned in that conversation; one no tool returned is removed and the answer says so.
  The sources row lists only cited IDs a tool returned, each linking to its page on the site. An
  answer with numbers and no tool call behind it is replaced by a refusal.
- **Marking:** every live answer carries the label "SI-generated answer" and the line "Answers
  are written by a language model from this site's data. Check the sources."
- **Stored answers:** five example answers in `apps/web/lib/assistant/stored-answers.json` were
  written with NO language model: `scripts/make-stored-answers.mjs` ran the same tools against
  the data service and filled sentence templates (code written with SI assistance). They are
  shown, labelled "Stored answer", when there is no key, the model fails or refuses, or a limit
  is reached.
- **Limits:** questions up to 800 characters, the last 8 messages of history, 8 questions per
  address per 10 minutes, at most 6 model rounds and 4 tool calls per round; the hard spend cap
  is the spend limit of the Anthropic workspace that owns the key.

SI also wrote text that ships in the product: the plain-language summaries and the tags of the 24
investigations in the catalog were drafted by a language model (Claude Sonnet 5.5, Anthropic)
before the build. It was given the PSI `objective` and `approach` text of each investigation and
nothing else. The text is stored in `pipeline/catalog/curation/investigations.yaml` with
`written_by`, goes into `data/build/catalog.sqlite`, and the site shows it under the label
"SI-written summary" next to the PSI record, which is always cited by PSI ID. A teammate reviews
the tags.

Not SI: the flame temperature numbers (Cantera and scikit-learn), the video measurements
(OpenCV, SciPy) and the PSI values. They are computed by our own code from the NASA data.

The T-series outcomes on the Spread page (`pipeline/video_to_data/t_series_grades.csv`,
`data/modules/video-to-data/`, records tagged `SI_EXTRACTED`).

- **What SI did:** a Claude Sonnet agent looked at brightened frames of 11 BASS-II T-series
  videos (PSI-25) and at the fan voltage read from the frames, and graded how each test ended
  (no ignition, quenched, blow-off, no blow-off, or could not tell).
- **What it was not given:** NASA's published outcomes, the Summary Report, the team's notes
  and earlier results. The grades were compared with Summary Report Table 7.1 afterwards.
- **How it is marked:** every grade carries the provenance tag "extracted by SI" and the flag
  `si_graded` (plus `low_confidence` where the grader said so); the page says it is a judgement
  by SI, not a measurement, and that the fan voltage history carries much of the answer.
- **What SI did not decide:** every number from the videos (ignition, flame gone, spread rate,
  fan timing) is computed by fixed rules in `pipeline/video_to_data/`, with no learned model.
  An SI viewing of contact sheets set each video's dark stretch and a "what was seen" label,
  which is shown as a flag and is not a hand measurement.
